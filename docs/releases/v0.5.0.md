## Copit 0.5.0

### Neu: Lieferstatus pro Ticket – auf einen Blick sehen, ob es fertig ist
Du musst nicht mehr in Git oder GitLab nachsehen. Copit zeigt zu jedem Agent bzw. Ticket die ganze Kette:

**Commit → Push → Merge Request → Pipeline → Jira**

- **Auf der Board-Karte:** farbige Symbole je Schritt und ein Satz als Urteil. Beispiele: „Gepusht · Pipeline grün · MR offen“, „Nicht gepusht – 2 Commits nicht gepusht“, „Pipeline fehlgeschlagen“.
- **In der Session:** ein Panel mit allen Schritten. Ein Klick auf einen Schritt öffnet ihn in GitLab bzw. Jira. Darunter die **Pipeline mit allen Jobs**, nach Stage gruppiert, mit Status und Dauer.
  - **Job-Log direkt in Copit:** „Log“ zeigt die letzten 200 Zeilen. Bei einer roten Pipeline öffnet Copit das Log des fehlgeschlagenen Jobs automatisch.
  - **Erneut starten:** startet eine fehlgeschlagene Pipeline neu.
- **Automatisch aktuell:**
  - Copit prüft nach jedem Lauf, nach dem Verschieben einer Karte (z. B. nach der Push-Automation) und alle paar Minuten im Hintergrund.
  - Solange eine Pipeline läuft, prüft Copit alle 30 Sekunden.
  - Wird die Pipeline grün oder rot, bekommst du eine Meldung.

### Fehlerbehebung: Buchen in Jira/Tempo
- **Account-Key statt Name.** Am Ticket steht der Tempo-Account oft nur als Name oder ID. Tempo braucht im Worklog aber den Account-*Key* und lehnte deshalb ab („… null“). Copit löst den Account jetzt vor dem Buchen in den Key auf. Das gilt auch für das Nachtragen eines Accounts an einer bestehenden Buchung.
- **Lesbare Fehler.** Lehnt Tempo trotzdem ab, zeigt Copit die Original-Meldung verständlich an: „Tempo lehnt die Buchung auf ST-1 ab (Account …): …“.

### Copilot: Eingabe-Tokens und Kosten
- **Eingabe-Tokens.** Meldet die Copilot CLI den Cache getrennt („↑ 3.1k (45.2k cached)“), wurden die Eingabe-Tokens bisher auf 0 gerechnet. Jetzt werden sie korrekt übernommen.
- **„Fertig“-Zeile.** Die Zeile nach jedem Lauf zeigt jetzt den Verbrauch, z. B. „↑ 48.3k (45.2k Cache) ↓ 812 Tokens · 1 Premium · $0.040“. So siehst du sofort, ob die Zahlen ankommen. Kommen keine Nutzungsdaten von Copilot, steht das dort.
- **AI Credits.** Für Konten mit AI-Credit-Abrechnung gibt es einen eigenen Preis unter Einstellungen → KI. Standard ist 0, also keine Berechnung.

### Fehlerbehebung: Diff in der Session
- **Schließen ging nicht.** Der Diff-Dialog in der Session ließ sich weder über das X noch per Klick daneben schließen. Ursache war eine Overlay-Ebene, die auf Windows alle Klicks schluckte. Jetzt ist die Ebene nur sichtbar, solange ein Dialog offen ist.
- **Neue Darstellung.** Der Diff nutzt jetzt dieselbe Ansicht wie „Änderungen pro Ticket“: ein Kopf pro Datei mit Status und ±-Zeilen, Zeilennummern alt und neu, Funktionskontext und hervorgehobene geänderte Wörter. Der Dialog hat außerdem weniger Rand.
