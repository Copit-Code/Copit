## Copit 0.4.10

### Copilot: Tokens und Kosten werden jetzt wirklich erfasst
- **Ursache.** 0.4.7 suchte nach einem älteren Ausgabeformat der Copilot CLI (`Total usage est …`). Die aktuelle CLI (1.x) gibt die Nutzung anders aus, deshalb blieb alles bei 0:
  ```
  Changes    +12 -3
  Requests   1 Premium (8s)
  Tokens     ↑ 12.6k (10.2k cached) • ↓ 297
  ```
- **Jetzt** liest Copit genau dieses Format aus der Copilot CLI 1.x:
  - Eingabe-, Ausgabe- und Cache-Tokens,
  - Premium Requests bzw. AI Credits,
  - geänderte Zeilen.

  Auch wenn die Pfeile durch die Konsolen-Codierung falsch ankommen, wird die Zeile erkannt. Die älteren Formate werden weiterhin erkannt.
- **Kosten für Copilot.** Copilot meldet keine Dollar-Beträge. Copit rechnet deshalb *Premium Requests × Preis*. Den Preis stellst du ein unter **Einstellungen → KI → GitHub Copilot CLI → Preis pro Premium Request**, Standard 0,04 USD, der Preis für zusätzliche Requests. Damit erscheinen Copilot-Kosten in Session, Activity und Budgets, und das Tageslimit lässt sich auch in USD setzen. Mit 0 schaltest du die Kosten ab.

Hinweis: Mit `-s`/`--silent` in den Copilot-Zusatzargumenten gibt die CLI keine Zusammenfassung aus. Läufe vor dem Update werden nicht nachträglich berechnet.
