What's inside

One cockpit for everything your agents do.

CLIs are great at writing code. They're bad at telling you what happened, what it cost and whether it shipped. Copit fills that gap.

→

Agents & board

Start Claude or Copilot agents in four modes and follow them from Inbox to Done — in parallel, each in its own git worktree.

 →

Changes per ticket

Every commit and uncommitted agent edit for a ticket, merged into one diff with file tree, line numbers and word-level highlights.

 →

Delivery status

Commit → Push → MR → Pipeline → Jira on every card. Job logs inside Copit, one-click pipeline retry, a ping when it turns green or red.

 →

Activity & budgets

AI time, tool time, tokens and dollars per day and week. Budgets per project with warning thresholds and an optional hard stop.

 →

Time tracking

AI-drafted worklogs from agent runs, commits and GitLab activity. Booked to Jira/Tempo with the right account — or internally.

 →

Automations

IF agent finished THEN comment in Jira. IF pipeline red THEN start a fix agent. Rules with conditions, placeholders and a test run.
Measured, not guessed

Know what every run cost.

Each run records wall-clock agent time, AI time, tool time, input and output tokens, dollars and changed lines. Activity rolls it up per agent, project, day and week.

  • Budgets as cost or hours — weekly, monthly or total, per project folder.
  • Warnings at 80 % and 100 %, optional hard stop that blocks new runs.
  • Daily limits per provider: dollars for Claude, hours or runs for Copilot.

How it works

Bring your own CLI. Copit does the rest.

Copit drives the official command-line tools you already use and trust. No proxy, no extra account, no cloud backend.

01

Install & sign in

Install Copit, then sign in once to claude or copilot in your terminal. Copit finds the paths for you.

02

Connect a project

A project ties a Jira epic, a source folder and a GitLab project together. Jira and GitLab are optional.

03

Start agents

Pick a ticket, a mode and a model. Agents work in parallel worktrees while you keep coding on your own branch.
