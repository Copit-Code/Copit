Extensions

Make Copit
fit your stack.

Extensions live in a GitHub repository or a local folder. Copit installs them, shows you exactly which commands they bring, and keeps them up to date.

What an extension can add

Five building blocks.

01

Agent templates

Pre-filled agents under New agent → Template, with placeholders like {{ticket}} and {{branch}}, a mode and allowed tools.

02

Actions

Scripts that show up in the automation builder as ext:<id>/<action>, with parameters and event variables.

03

Recipes

Ready-made automations — imported switched off, so you review them before they run.

04

Permission rules

Allow / Ask / Deny rules, adopted as Copit rules only after you confirm.

05

Your own tools

A full tool with its own navigation entry — for example an MCP prompt tool with presets.

↻

Auto-updates

Copit checks for new releases or commits at startup and every 6 hours and reports updates.

Install

Point Copit at a repo.

SourceMeaning
owner/repoLatest release with *.copit.zip, otherwise the default branch
owner/repo@v1.2.0A specific release, tag or branch
owner/repo/pathA folder inside a repo
https://github.com/…/tree/main/dirSame, as a URL

Public repos work without sign-in; private ones need a GitHub token with “Contents: Read-only”. For development, load a local folder and hit “Reload”.

copit-extension.jsonmanifest
{
  "id": "my-extension",
  "name": "My Extension",
  "version": "1.0.0",
  "agentTemplates": [{
    "id": "tests",
    "title": "Tests for {{ticket}}",
    "mode": "Edit",
    "prompt": "Write tests for {{ticket}} …",
    "branch": "test/{{ticket}}",
    "allowedTools": ["Bash(dotnet test:*)"]
  }],
  "actions": [{
    "id": "test",
    "label": "dotnet test",
    "run": "powershell -File \"{ext}/scripts/test.ps1\""
  }],
  "automations": [{
    "id": "test-after-agent",
    "trigger": "agent.finished",
    "actions": [{ "type": "ext:my-extension/test" }]
  }],
  "permissions": [
    { "pattern": "Bash(dotnet test:*)", "level": "Allow" }
  ]
}
Security. Actions run commands with your permissions. Copit shows every command an extension brings before installing it — only install extensions from sources you trust.
