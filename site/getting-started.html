Get started

From download to
first agent in five steps.

You need Windows and at least one AI CLI. Jira and GitLab are optional.

  1. Install Copit

    Windows app: open the latest release and run Copit-Setup-X.Y.Z.exe. It installs per user to %LOCALAPPDATA%\Programs\Copit — no admin rights needed. Prefer portable? Unzip Copit-X.Y.Z-win-x64-portable.zip and start Copit.exe.

    Updates are automatic: Copit checks at startup and every 6 hours, downloads the installer and restarts.

    SmartScreen: the installer isn't signed yet, so Windows may show “Windows protected your PC”. Click More info → Run anyway.

    VSCodium extension:

    ./scripts/setup-vscodium.ps1 -Repo "Copit-Code/Copit"

    This downloads portable VSCodium, installs Copit plus the “Copit Dark” theme, Solution Explorer and C# IntelliSense from Open VSX, and creates a desktop shortcut. The extension updates itself too.

  2. Provide an AI CLI

    Copit drives the official command-line tools. Install and sign in to at least one:

    CLIInstallSign in
    Claude Codenpm i -g @anthropic-ai/claude-code or the native installerRun claude once
    GitHub Copilot CLInpm i -g @github/copilotRun copilot once

    Under Settings → AI Copit detects the paths automatically — hit Test to check. Set your default provider, model, global instructions and, optionally, the token-saving script library there.

  3. Connect Jira and GitLab optional

    • Jira: URL and token (Bearer or Basic). Optionally Tempo (account attribute), account field, epic link field and default issue type.
    • GitLab: URL and a personal access token with read_api — api for merge requests and pipeline actions.

    Without Jira, time tracking is stored internally — even without a ticket.

  4. Create your first project

    Open Projects → New project, enter a Jira epic such as SHOP-100 and confirm with Check. Pick the source folder — Copit detects the GitLab project from the Git remote. Optionally put it in a folder like Customer A/Backend and add AI instructions such as “.NET 9, xUnit, commits in English”.

  5. Start your first agent

    Open Agents → New agent, choose the project, title, ticket and task, and a mode: Ask, Plan, Edit or Auto. With a branch and “own worktree” the agent works in parallel without touching your working copy.

    The card moves across the board — Inbox → In progress → Review → Done. Click it to open the session with transcript, tool calls, sub-agents and metrics. Changes shows the ticket's code.

Your data

Everything stays on your machine.

Projects, sessions, automations, budgets and settings live in %LOCALAPPDATA%\Copit. Secrets such as tokens are encrypted with Windows DPAPI. No Copit cloud, no account.
