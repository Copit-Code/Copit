Agents & sessions

A Kanban board for AI agents.

Inbox → In progress → Review → Done. Drag cards around; the card menu opens, stops, archives or deletes an agent, sets its status or jumps to the ticket's code changes.

New agent

Four modes, two providers

Choose project, title, ticket, branch and task, then Claude or Copilot, a model and a mode: Ask, Plan, Edit or Auto. Optionally give every agent its own git worktree so several can work in parallel without touching your working copy. Templates from extensions pre-fill the form.

Session

Watch it think and work

A live transcript with text, tool calls and sub-agents. Questions from the agent appear as choices — answer several at once and send them together. Missing permissions can be granted once or permanently.

Metrics

Every run is measured

Agent time (wall clock), AI time, tool time, tokens, cost and changed lines — recorded per run, shown in the session and rolled up in Activity.

Context

Prompts you reuse

Choose the context window per agent and keep recurring tasks in the prompt library instead of retyping them.

Changes per ticket

All the code behind a ticket.

Copit collects every commit that belongs to a ticket — by key in the message or in the branch name, across all branches including remotes — plus the uncommitted work of its agents.

  • Overview of all tickets with commits in a period: Jira title, commits, files, ±lines, authors.
  • Combined change per file, a single commit, or an agent's uncommitted work (worktrees too).
  • File tree with status and ± bars; diffs with old/new line numbers, function context and word highlights.
  • Click a line number to open the file right there in VS Code or VSCodium.
  • Exact key matching — SHOP-1 never matches SHOP-12.

Delivery status · new in 0.5

Commit → Push → MR → Pipeline → Jira.

Every card shows how far its ticket has shipped, with one sentence as the verdict: “Pushed · pipeline green · MR open” or “Not pushed — 2 commits ahead”.

  • Session panel with every step; one click opens it in GitLab or Jira.
  • Pipeline jobs grouped by stage with status and duration.
  • Job logs in Copit — the last 200 lines; a red pipeline opens the failing job automatically.
  • Retry a failed pipeline right there.
  • Always fresh: after each run, after moving a card, in the background — every 30 s while a pipeline runs, with a notification when it turns green or red.

Activity & budgets

Spend you can see — and cap.

Day and week views with timelines per agent and project, split into AI time, agent time and tool time, with tokens and dollars. Real Claude sessions you ran outside Copit are included.

Budgets

Cost or hours

Per week, month or in total. Scoped to specific project folders or to everything.

Thresholds

Warn, then stop

Warnings at e.g. 80 % and 100 %. With the optional hard stop, new runs are blocked once the budget is spent.

Daily limits

Per provider

A dollar limit for Claude; hours or runs for Copilot — including premium requests and AI credits pricing.

Projects

Epic, repo and pipeline — tied together.

A project connects a Jira epic, a source folder, a GitLab project, a colour and AI instructions such as “.NET 9, xUnit, commits in English”.

  • Folders like Customer A/Backend — collapsible, drag & drop, rename and move.
  • Project page with the epic's ticket board, notes and sessions.
  • New ticket drafted and estimated by AI.
  • Start a session from a ticket, with or without a branch.

Living docs

Documentation that writes itself into your repo.

Copit generates linked Markdown under /docs in each project's repository — rendered directly by GitHub and GitLab. Generated blocks sit between markers, everything else you write stays untouched. A docs agent adds descriptions and may only write inside docs/.

Customize

You decide what agents may do.

Allow, Ask or Deny for tools and commands — including a matrix for Git operations. Copit passes the rules to the CLIs and respects your Claude settings.json.

  • Script library: agents write small scripts for repetitive work (search, log filtering, test summaries) and call them instead of dozens of tool calls — fewer tokens.
  • Compact index of available scripts in the system prompt; only library scripts may run, usage is counted.
  • Global or per project: %LOCALAPPDATA%\Copit\scripts or .copit/scripts in the repo.
  • Integrations for Jira, GitLab and auto-update. Secrets are encrypted with Windows DPAPI.
