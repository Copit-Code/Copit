Automations

IF this happens,
THEN Copit does that.

Rules made of a trigger, optional conditions and one or more actions. Placeholders carry values from the event into every action — and each rule has a test run, so you know it works before it fires for real.

Example

Ship when the card says done.

Move a card from Review to Done and Copit pushes exactly that card's branch. If nothing was pushed, it tells you.

Placeholders like {{ticket}}, {{title}}, {{summary}}, {{branch}}, {{from}} and {{to}} are filled from the event.

Triggers

When something happens

  • Agent started, finished, needs input, failed or stopped
  • Card moved, with from- and to-column
  • Git: new commit, push, new branch
  • Pipeline failed or succeeded
  • Jira: ticket status changed, ticket assigned — narrowed by JQL
  • Schedule: time of day and weekdays
Actions

What Copit does

  • Agents: set status, start a new agent, continue an agent, notify
  • Jira: comment, change status, book time, check hours
  • Git: commit, push (also the card's branch), create branch, merge request
  • More: update docs, ask the AI, run a command
  • Extensions: any action an extension ships, as ext:<id>/<action>
Built-in recipes

Start from a recipe.

Copit ships with ready-made rules — some switched off by default, so nothing happens until you say so.
