# Copit – Agent IDE für VSCodium

KI-Agents (Claude CLI / Copilot CLI) direkt im Editor:

- **Board** – Kanban mit Inbox · In Progress · Waiting for Subagent · Need Input · Review · Done · Failed, Drag & Drop
- **Agent-Tab** – AI-Zeit, Agent-Zeit, Tool-Zeit, Kosten, Kontext, Flow-Baum inkl. Sub-Agents, Diff-Review, Rückfragen & Freigaben
- **Kalender** – welcher Agent wann lief
- **Budgets** – pro Projekt (Woche/Monat/gesamt, USD oder Stunden), Warnschwellen, Hard Stop, Gesamtübersicht
- **Customize** – Permission-Regeln (global, Projekt, Copit) und Git-Matrix
- **Automationen** – Builder für Agent-, Git-, GitLab- und Jira-Ereignisse
- **Auto-Update** über GitHub-Releases

Alle Daten liegen lokal in SQLite (`copit.db` im Extension-Speicher).
